# Technical Documentation

Welcome to the technical documentation for marine meteorology systems at the **Center for Marine Meteorology** (DMM), BMKG.

This site covers the numerical models and workflows used to support marine weather forecasting, early warning, and decision-making for severe weather and marine hazards across the Indonesian archipelago.

## Documentation sections

### [InaCAWO](inacawo/index.md)

**Indonesia Coupled Atmosphere–Wave–Ocean** is a three-way coupled atmosphere–wave–ocean modelling system that replaces previously independent atmospheric, wave, and ocean models. InaCAWO provides higher spatial resolution and improved physical coupling between model components for more accurate simulation of complex air–sea processes.

- [Overview](inacawo/overview/index.md) — system background and capabilities
- [Configuration](inacawo/overview/configuration.md) — model setup and parameters
- [Operational flow](inacawo/operational/index.md) — production, dissemination, and troubleshooting
- [Tutorial](inacawo/tutorial/index.md) — hands-on forecast and hindcast guides

### [SWAN](swan/index.md)

**Simulating WAves Nearshore** is a third-generation spectral wave model developed at Delft University of Technology. Within InaCAWO, SWAN simulates wave dynamics in coastal and nearshore areas. This documentation also covers standalone SWAN usage.

- [Overview](swan/overview/index.md) — role of SWAN within and outside InaCAWO
- [Introduction](swan/introduction/introduction.md) — wave theory and model fundamentals
- [Tutorial](swan/tutorial/index.md) — installation, data preparation, configuration, and visualization
